## 图3-3 四策略联动决策流程图

```
                        开始
                         │
                         ▼
                  ┌──────────────┐
                  │ 快照所有活跃  │
                  │ 通道状态      │
                  └──────┬───────┘
                         │
                         ▼
                    ┌─────────┐
                    │ 有活跃   │─── 否 ──► [all_clear]
                    │ 通道?   │           无活跃监测通道
                    └────┬────┘
                         │ 是
                         ▼
                    ┌─────────┐
                    │ 所有安全 │─── 是 ──► [emergency]
                    │ 通道均有 │           所有通道火灾
                    │ 火灾?    │           立即紧急疏散
                    └────┬────┘
                         │ 否
                         │
                         ▼
                  ┌──────────────┐
                  │ 计算各通道    │
                  │ 饱和度 sat =  │
                  │ count /       │
                  │ threshold_warn│
                  └──────┬───────┘
                         │
                         ▼
                    ┌─────────┐
                    │ 有拥挤/  │─── 否 ──► [all_clear]
                    │ 火灾通道?│           各通道畅通
                    └────┬────┘           无需引导
                         │ 是
                         │
                         ▼
                    ┌─────────┐
                    │ 有畅通   │─── 是 ──► [guided]
                    │ 安全通道?│           推荐畅通安全通道
                    │alarm=0 & │           按饱和度升序排列
                    │sat <0.8  │
                    └────┬────┘
                         │ 否
                         │
                         ▼
                    [degraded]
                    全部通道接近容量上限
                    建议分批通行
```

**画法提示：**
- draw.io 选"流程图"模板
- 圆角矩形=处理步骤，菱形=判断节点，方角矩形=策略结果
- 四种策略结果用不同颜色：all_clear 绿色、guided 黄色、degraded 橙色、emergency 红色
- 判断分支的"是/否"标签写在线旁边
- 在 emergence 和 degraded 节点旁边加小字标注触发条件

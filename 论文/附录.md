## 附录A：部分核心代码

### A.1 检测主循环伪代码（detector.py — detect_loop）

```
输入: channel ∈ {'A', 'B', 'C'}
输出: 实时帧画面 + 人数统计 + 报警等级

1.  初始化 source ← None, frame_count ← 0, fps_timer ← now()
2.  相位错开: sleep({'A':0, 'B':5.6ms, 'C':11.1ms}[channel])
3.  LOOP:
4.    IF 通道暂停(channel_active[channel] == False):
5.      sleep(0.5s) → CONTINUE
6.    // 手动重播检测
7.    IF 重播标志置位:
8.      关闭旧视频源 → source ← None
9.    // 视频源配置变更检测
10.   IF source_config 与 last_cfg 不同:
11.     关闭旧源 → source ← None → 清空帧缓存
12.   // 打开/重连视频源
13.   IF source == None:
14.     source ← _open_source(channel)  // 按配置打开MJPEG或MP4
15.     IF 打开失败: sleep(3s) → CONTINUE
16.   // 读取一帧
17.   frame ← _read_frame(source)
18.   IF frame == None:  // EOF或断连
19.     IF MP4: seek到开头并验证，失败则重新打开
20.     IF MJPEG: 清帧缓存 + 重试
21.     CONTINUE
22.   // YOLOv8推理（缩略图）
23.   small ← cv2.resize(frame, (320, 240))
24.   results ← model(small, conf=0.5)
25.   count ← 统计 person 类别的检测框数量
26.   // 三级报警防抖（每通道独立阈值）
27.   target ← get_target_level(count, channel)  // 0/1/2
28.   IF target != old_level AND 不在锁定状态:
29.     consecutive ← consecutive + 1
30.     IF consecutive >= 3:  // 连续3帧确认
31.       切换报警等级，记录事件到数据库
32.       IF 升级: 钉钉报警通知
33.       IF 解除: 钉钉解除通知 + 数据库结案
34.   ELSE IF target == old_level:
35.     normal_frames += 1  // 复位防抖计数器
36.   // 画框标注
37.   annotated ← 在frame上绘制检测框 + 通道标签 + 人数/FPS
38.   更新 channel_state[channel].frame ← annotated
39.   // 每1s写入数据库
40.   IF now - last_db_write >= 1s:
41.     insert_detection(count, level, fps, channel)
42.   // FPS统计（每2s刷新）
43.   IF now - fps_timer >= 2s:
44.     fps ← frame_count / 2.0
45.   // 每0.3s触发联动决策
46.   IF now - last_coord_time >= 0.3s:
47.     coordinated_decision()
48.   // 帧率上限控制（~15fps）
49.   sleep(66.7ms - 本次循环耗时)
```

### A.2 联动决策伪代码（detector.py — coordinated_decision）

```
输入: channel_state (全局共享状态), device_bindings
输出: recommended_exit + 每设备STM32指令 + MQTT仪表盘SIG

1.  快照所有活跃通道的 {count, alarm_level, fire, active, threshold_warn}
2.  // 火焰传感器状态注入（按设备绑定）
3.  FOR EACH (dev_id, channel) IN device_bindings:
4.    IF devices[dev_id] 在线且火焰信号:
5.      snap[channel].fire ← True
6.  // 联动推荐
7.  active_list ← 过滤活跃通道
8.  IF active_list 为空:
9.    strategy ← 'all_clear', message ← '无活跃监测通道'
10. ELSE:
11.   fire_channels ← 过滤火灾通道
12.   safe_active ← active_list 排除火灾通道
13.   IF safe_active 为空:
14.     strategy ← 'emergency', message ← '所有通道发生火灾！请立即远离'
15.   ELSE:
16.     // 计算饱和度 = count / threshold_warn
17.     FOR EACH ch IN safe_active:
18.       sat[ch] ← snap[ch].count / max(snap[ch].threshold_warn, 1)
19.     clear_chs ← safe_active中 alarm_level==0 且 sat<0.8
20.     crowded_chs ← safe_active中 alarm_level>0 或 sat>=0.8
21.     IF crowded_chs 为空 AND fire_channels 为空:
22.       strategy ← 'all_clear', message ← '各通道畅通，无需引导'
23.     ELSE IF clear_chs 非空:
24.       exits ← clear_chs 按饱和度升序排列
25.       strategy ← 'guided', message ← '建议人员前往：{exit_names}'
26.     ELSE:
27.       exits ← safe_active 按饱和度升序排列
28.       strategy ← 'degraded', message ← '各通道接近容量上限，请分批通行'
29. // 每设备独立STM32指令生成
30. FOR EACH (dev_id, channel) IN device_bindings:
31.   IF 设备在线:
32.     lv ← 2 IF (fire OR manual_alarm) ELSE alarm_level
33.     buz ← 1 IF lv >= 1 ELSE 0
34.     servo ← 1 IF lv >= 2 ELSE 0
35.     生成指令: "LV:{lv},BUZ:{buz},SERVO:{servo}"
36.     按设备独立节流发送MQTT指令
37. // 构造仪表盘SIG消息并广播
38. sig ← "A:{count},LA:{level},B:{count},LB:{level},..."
39. IF sig 变化且距上次>=0.5s: broadcast(sig)
```

## 附录B：引导算法测试用例详情

以下七个测试场景覆盖了四策略联动引导算法的全部决策路径，测试通过 `test_guidance.py` 自动化执行。

**系统默认参数**：红色阈值=20，黄色阈值=12（场景7为自定义阈值）。

| # | 场景名称 | 通道状态 | 输入条件 | 预期策略 | 预期推荐出口 | 验证要点 |
|---|---------|---------|---------|---------|------------|---------|
| 1 | 三通道全绿 | A绿(3人) B绿(5人) C绿(2人) | 全活跃，全无火 | `all_clear` | `[]`（无） | 畅通时不做无意义引导 |
| 2 | 一黄两绿 | A黄(15人) B绿(5人) C绿(3人) | 全活跃，全无火 | `guided` | `['C', 'B']` | 按饱和度排序（C:0.25 < B:0.42） |
| 3 | 全部接近阈值 | A黄(13人) B黄(14人) C黄(15人) | 全活跃，全无火 | `degraded` | `['A', 'B', 'C']` | 无畅通通道时降级建议分批通行 |
| 4 | 单通道火灾 | A绿(5人) B火(10人) C绿(3人) | B火灾，A/C畅通 | `guided` | `['C', 'A']` | 火灾通道被排除在推荐外 |
| 5 | 全通道火灾 | A火(5人) B火(10人) C火(3人) | 全部火灾 | `emergency` | `[]`（无） | safe_active为空→紧急疏散 |
| 6 | 暂停通道排除 | A暂停(0人) B黄(15人) C黄(18人) | A暂停，无火 | `degraded` | `['B', 'C']` | 暂停通道不参与推荐 |
| 7 | 不同阈值组合 | A绿(10/15) B绿(8/12) C黄(13/12) | 全活跃，无火，A阈值高B标准C标准 | `guided` | `['A', 'B']` | 饱和度跨阈值比较正确（A:0.67, B:0.67, C:1.08） |

**测试结果**：7/7 场景全部通过，数据结构验证（recommended_exit字段完整性、SIG格式）全部通过。

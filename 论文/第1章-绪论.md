# 第1章 绪论

## 1.1 研究背景与意义

### 1.1.1 校园安全管理的现实需求

　　随着我国高等教育事业的快速发展，高校校园规模不断扩大，在校师生人数持续增长。以教学楼、食堂、图书馆为代表的人员密集场所，在上下课高峰时段往往出现短时间内人流量激增的情况，极易引发拥挤踩踏等安全事故。与此同时，高校校园建筑结构复杂、出口众多，一旦发生火灾等突发紧急事件，缺乏有效的实时监测与智能疏散引导手段，将严重威胁师生生命财产安全。

　　当前，大多数高校的校园安全管理仍主要依赖人工巡逻和固定摄像头监控相结合的传统模式。安保人员通过视频监控墙进行人工观察，辅以定期巡逻来发现异常情况。这种模式存在以下显著不足：第一，实时性差，安保人员无法同时对数十个监控画面进行持续有效的关注，异常事件往往在发生后才能被发现；第二，覆盖面有限，夜间或节假日期间巡逻频次降低，存在大量监控盲区时段；第三，缺乏定量分析能力，人工观察只能定性判断人流稀疏或密集，无法精确统计人数并进行趋势预警；第四，应急响应滞后，从发现异常到启动疏散引导依赖人工决策和多级传达，响应时间以分钟计，在火灾等场景下可能错过最佳疏散窗口。

　　因此，设计一套能够实时监测校园重点区域人流量、自动识别异常拥堵状态、并在紧急情况下联动硬件设备进行智能疏散引导的综合管理系统，具有重要的现实意义和应用价值。

### 1.1.2 智能监控技术的应用现状

　　近年来，以深度学习为代表的计算机视觉技术在安防监控领域得到了广泛应用。基于卷积神经网络（CNN）的目标检测算法，如 YOLO（You Only Look Once）系列[1-3]，能够在视频流中实时检测并计数行人，检测精度和速度均已达到实用化水平。与此同时，物联网（IoT）技术的快速发展使得低成本传感器节点的大规模部署成为可能，各类环境传感器（火焰、烟雾、温湿度等）通过无线通信协议接入统一平台，为传统视频监控提供了物理维度的冗余信息[4]。

　　在多模态融合方面，越来越多的研究开始探索将视觉检测与传感器数据相结合的方法。例如，通过融合摄像头图像与红外热成像数据进行火灾检测，或结合 WiFi 信号强度分布与视频分析进行室内人流密度估计[5-6]。这种多源信息互补的思路正在成为智能安防领域的主流趋势。

　　在通信协议方面，MQTT（Message Queuing Telemetry Transport）协议凭借其轻量级、低带宽、发布/订阅模式等特点，已成为物联网领域事实上的标准通信协议之一[7]。它能够在网络条件不稳定的情况下保持可靠的消息传递，非常适合于校园监控系统中多设备间的实时数据交换。

### 1.1.3 本课题的研究意义

　　本课题设计并实现了一套"应急场景下的校园人流量监控管理系统"，其研究意义体现在以下几个方面：

　　**双通道互补架构**：系统采用"AI 视觉检测 + 本地物理传感器"的双输入通道设计。日常运行状态下，以 YOLOv8 深度学习模型的视觉检测为主要人流量统计手段；在火灾等紧急场景下，火焰传感器直接触发硬件响应，不依赖网络和 AI 运算，保证了应急情况下的系统可靠性。这种双通道互补的设计思路，较好地兼顾了日常检测的智能性与应急响应的鲁棒性。

　　**低成本可扩展**：系统后端以普通 PC（搭载消费级 GPU）为 AI 运算平台，前端基于 ESP32-CAM 低成本摄像头模块采集视频，控制端采用 STM32F103 微控制器驱动 LED、蜂鸣器和舵机等执行器件，通信通过 ESP8266 WiFi 模块和公共 MQTT Broker 实现。整体硬件成本控制在较低水平，且支持多 STM32 设备的自动发现与即插即用，具备良好的可扩展性。

　　**检测→决策→执行→通知的完整闭环**：系统不仅实现了人流量检测，还构建了从检测（YOLO 视觉计数 + 火焰传感器）、联动决策（三级报警 + 四策略引导算法）、执行（STM32 硬件控制闸门/蜂鸣器）到通知（钉钉机器人实时推送）的完整闭环链路。这一闭环体系使得系统在检测到异常后能够自动完成决策、执行和信息触达的全过程，无需人工干预。

## 1.2 国内外研究现状

### 1.2.1 基于视觉的人流量统计研究

　　基于计算机视觉的人流量统计是智能监控领域的核心研究方向之一。从方法论角度，相关研究可大致分为传统方法与深度学习方法两个阶段。

　　传统方法主要依赖于手工设计的特征提取器和分类器。例如，Dalal 等人提出的 HOG（Histogram of Oriented Gradients）特征结合 SVM 分类器的行人检测方法[8]，在早期取得了较好的效果。基于背景减除（Background Subtraction）的运动目标检测方法，如 MOG（Mixture of Gaussians）和 ViBe 等算法[9]，通过建模背景分布来提取前景运动目标，再结合形态学操作和连通域分析进行人数统计。然而，这些传统方法在密集人群、光照变化、遮挡严重等复杂场景下性能下降明显，难以满足实际部署需求。

　　2012 年以来，深度学习技术的突破为人流量统计带来了革命性的进步。基于 CNN 的目标检测算法经历了从 Two-stage（如 Faster R-CNN[10]）到 One-stage（如 SSD[11]、YOLO 系列）的演进。Two-stage 方法先生成候选区域再进行分类，检测精度较高但速度较慢；One-stage 方法直接在特征图上回归目标位置和类别，速度显著提升，更适合实时监控场景。YOLO 系列自 2016 年提出以来，经历了多个版本的迭代，其中 YOLOv8 由 Ultralytics 公司于 2023 年发布[1]，在检测精度和速度之间取得了优秀的平衡，其轻量级版本 YOLOv8n 仅有 3.2M 参数，在消费级 GPU 上可实现每秒数十帧的推理速度，非常适合校园监控等边缘计算场景。

### 1.2.2 应急疏散与引导系统研究

　　应急疏散与引导系统是公共安全领域的重要研究方向。传统的疏散引导主要依赖静态指示牌和应急广播，其引导策略是固定的，无法根据实时人流分布动态调整。近年来，随着传感器网络和智能决策算法的发展，动态疏散引导系统逐渐成为研究热点[12-13]。

　　在火灾检测方面，多传感器融合已成为主流方法。通过同时采集烟雾浓度、温度、火焰光谱等多元物理量，利用加权融合或贝叶斯推理等算法综合判断火灾发生的概率，可以有效降低单一传感器的误报率[14]。在引导策略方面，基于图论的最短路径算法、蚁群优化算法以及基于元胞自动机的人群疏散仿真等方法已被广泛研究[15]。然而，多数研究停留在仿真验证阶段，较少有系统将检测、决策与实际的硬件执行设备（如闸门、蜂鸣器等）直接联动。

### 1.2.3 现有研究的不足与本课题的技术路线

　　综合分析现有研究，存在以下几个方面的不足：

　　第一，**单输入通道的脆弱性**。大多数系统要么仅依赖视觉检测，在网络中断或摄像头故障时完全失效；要么仅依赖物理传感器，缺乏人流统计的定量能力。缺乏两者互补的冗余设计。

　　第二，**缺乏完整的决策-执行闭环**。大量研究集中于检测算法的精度提升或疏散路径的理论计算，很少将检测结果、决策算法与实际的嵌入式硬件控制设备直接联动。从发现异常到执行引导之间存在人工操作环节，应急响应存在延迟。

　　第三，**成本与可扩展性考虑不足**。许多智能监控系统依赖昂贵的服务器集群和专用网络设备，难以在普通高校推广。同时，系统设计缺乏对多通道、多设备场景的可扩展性考量。

　　针对以上不足，本课题的技术路线为：以 AI 视觉检测（YOLOv8n）和物理火焰传感器构成双输入通道，通过联动决策引擎进行三级报警判定和四策略人流引导，经由 MQTT 协议向 STM32 嵌入式控制平台下发控制指令，实时驱动舵机闸门、蜂鸣器等执行设备，同时通过钉钉机器人向管理人员推送报警通知。整套系统在普通 PC 上运行，硬件成本可控，并支持多 STM32 设备的自动发现与动态绑定，具备良好的可扩展性。

## 1.3 主要研究内容

　　本课题的主要研究内容包括以下五个方面：

　　**（1）三通道实时人流量检测**。基于 YOLOv8n 深度学习模型，实现 A、B、C 三个独立通道的并行行人检测与计数。每通道支持 MJPEG 实时视频流（ESP32-CAM）和 MP4 本地视频文件两种输入源，可在运行时动态切换。三通道检测线程通过相位错开机制避免 GPU 资源的竞争冲突，并通过对称防抖算法（连续三帧确认）消除人数统计在阈值附近的抖动问题。

　　**（2）三级报警与联动决策算法**。设计并实现三级报警体系：0 级正常（人数 ≤ 黄色阈值）、1 级黄色预警（黄色阈值 < 人数 ≤ 红色阈值）、2 级红色报警（人数 > 红色阈值），每通道可独立设置报警阈值。在此基础上，实现四策略人流引导算法：all_clear（全部畅通，无需引导）、guided（有拥挤通道且有安全替代出口，按饱和度排序推荐）、degraded（所有安全通道接近容量上限，建议分批通行）、emergency（全部通道火灾，紧急疏散）。

　　**（3）STM32 嵌入式执行系统**。以 STM32F103ZET6 为主控芯片，通过 GPIO 驱动红黄双色 LED、有源蜂鸣器，通过 TIM3 PWM 控制 SG90 舵机闸门。火焰传感器通过 PA0 引脚接入，在 MCU 端实现 100ms 周期的三级防抖，确保火灾检测的可靠性。系统通过 USART2 串口与 ESP8266 WiFi 模块通信，接收来自服务端的控制指令，同时上传火焰传感器状态。

　　**（4）MQTT 多设备通信协议**。基于 MQTT 协议构建系统各组件间的通信体系。服务端通过通配符订阅（`bishe/99257/+/status`、`bishe/99257/+/flame`）自动发现在线 STM32 设备，并向指定设备下发 LV:BUZ:SERVO 格式的控制指令。ESP8266 固件利用遗嘱消息（Last Will Testament）机制实现设备离线自动通知，确保设备状态的实时追踪。

　　**（5）Web 仪表盘可视化系统**。基于 Flask 框架构建 Web 服务端，提供 15 个 API 路由，涵盖视频流推送、状态查询、阈值调节、视频源切换、设备绑定、监测启停等功能。前端采用 Chart.js 实现三通道动态折线图（1 秒刷新、秒对齐时间轴），支持 MJPEG 视频流实时展示、应急双态模式（紧急状态下红色顶部栏 + 折线图折叠 + 疏散引导面板突出）以及移动端响应式布局。

## 1.4 论文结构安排

　　本论文共分为六章，各章内容安排如下：

　　**第1章 绪论**。介绍课题的研究背景与意义，分析国内外在视觉人流量统计、应急疏散与引导系统等领域的研究现状，指出现有研究的不足，阐述本课题的技术路线和主要研究内容。

　　**第2章 相关技术介绍**。介绍系统涉及的核心技术，包括 YOLOv8 目标检测算法的原理与结构、MQTT 通信协议的机制与应用、嵌入式系统技术（ESP32-CAM、STM32F103、ESP8266），以及 Web 开发技术（Flask 框架和 Chart.js 可视化）。

　　**第3章 系统设计与架构**。详细阐述系统的总体架构设计、双输入通道机制、三级报警与联动决策算法、四策略人流引导算法的设计与实现，以及 MQTT 通信协议的 Topic 设计和多设备管理方案。

　　**第4章 系统实现**。介绍各模块的具体实现细节，包括 YOLOv8 检测引擎的多线程架构、STM32 嵌入式固件的寄存器级驱动、ESP32-CAM 的视频采集与帧率优化、ESP8266 MQTT 透传固件，以及 Web 仪表盘的前端交互设计。

　　**第5章 系统测试与分析**。展示系统在模拟场景下的测试结果，包括三级报警功能测试、联动决策算法场景测试、多设备通信可靠性测试、Web 仪表盘功能验证，以及系统性能分析。

　　**第6章 总结与展望**。总结本课题的研究成果和主要贡献，分析系统当前的局限性，并对未来的改进方向进行展望。

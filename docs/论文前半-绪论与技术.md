## 章节大纲（精确到 1.1.1）

### 第1章 绪论

**1.1 研究背景与意义**
  1.1.1 校园安全管理的现实需求
    - 高校校园人流量大、密集场景多（上下课、食堂、图书馆）
    - 传统管理依赖人工巡逻，实时性差、覆盖面小
    - 火灾等应急场景下缺乏智能疏散引导
  1.1.2 智能监控技术的应用现状
    - AI 视觉检测在安防领域的普及趋势
    - 物联网传感器在环境监测中的应用
  1.1.3 本课题的研究意义
    - 双通道互补：AI视觉（日常）+ 本地传感器（应急冗余）
    - 低成本可扩展：单MCU控制多通道联动
    - 实时决策+硬件联动+推送通知的闭环体系

**1.2 国内外研究现状**
  1.2.1 基于视觉的人流量统计研究
    - 传统方法（HOG+SVM、背景减除）vs 深度学习方法（CNN、YOLO系列）
  1.2.2 应急疏散与引导系统研究
    - 静态指示牌 vs 动态引导算法
    - 多传感器融合在火灾检测中的应用
  1.2.3 现有研究的不足与本课题的技术路线
    - 多数系统单一依赖视觉或传感器，缺乏互补
    - 缺乏从检测→决策→执行→通知的完整闭环
    - 本课题：AI视觉+火焰传感器双输入 → 联动决策引擎 → STM32硬件控制 + 钉钉推送

**1.3 主要研究内容**
  - 三通道实时人流量检测（YOLOv8n + MJPEG/MP4双视频源）
  - 三级报警+火焰防抖的联动决策算法
  - 四策略人流引导算法（all_clear/guided/degraded/emergency）
  - STM32嵌入式执行系统（舵机闸门+蜂鸣器+火焰传感器）
  - MQTT多设备通信协议
  - Web仪表盘可视化（实时视频+折线图+设备管理）

**1.4 论文结构安排**
  - 简述各章内容分布

### 第2章 相关技术介绍

**2.1 目标检测技术**
  2.1.1 深度学习目标检测概述
    - Two-stage vs One-stage 对比，选YOLOv8n理由
  2.1.2 YOLOv8 模型结构与原理
    - Backbone(CSPDarknet)+Neck(FPN+PAN)+Head(Decoupled)，n版3.2M参数
    - COCO预训练+自定义数据集微调

**2.2 MQTT通信协议**
  2.2.1 MQTT协议概述 — 发布/订阅、QoS、LWT、保留消息
  2.2.2 MQTT在本系统中的应用 — Broker选型、Topic设计、遗嘱消息、通配符订阅

**2.3 嵌入式系统技术**
  2.3.1 ESP32-CAM 视频采集 — OV2640传感器、MJPEG编码、XCLK/帧率优化
  2.3.2 STM32F103 控制平台 — Cortex-M3架构、外设、HAL库与寄存器混合编程
  2.3.3 ESP8266 WiFi透传 — Arduino SDK固件、UART串口桥接、双向透传

**2.4 Web开发技术**
  2.4.1 Flask轻量级Web框架 — 路由、Jinja2模板、多线程
  2.4.2 前端可视化技术 — Chart.js折线图、MJPEG流展示、响应式布局

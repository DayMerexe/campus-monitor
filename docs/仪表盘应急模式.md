# 仪表盘应急模式

> 子对话入口文档：重构仪表盘应急场景信息层级，做正常/紧急双态切换。

---

## 用户的意图（请仔细读）

当前仪表盘偏"常态化监控大屏"——玻璃态暗色系，信息均匀分布。但应急场景下核心需求变了：

**"哪里着火了？哪里安全？我往哪走？"** — 三秒内要有答案。

不需要改后端，数据 `/dashboard` 已返回（`anyFire`、`recommended_exit`、各通道 `fire`/`alarm_level`）。

---

## 具体改动

### 1. 推荐面板双态（灵魂改动）

**正常态：** 保持现有低调一行布局。

**紧急态（anyFire 或任意通道 alarm_level >= 2）：**
- 撑满全宽，脱离中间行独立成段
- 大面积色块背景（火灾红/安全绿）
- 大号疏散箭头 + 文字："→ 出口X 安全撤离"

### 2. 火灾/安全通道视觉强化

- 火灾通道视频窗口：大面积红色边框 + 底色（加强现有 `.fire-overlay`）
- 安全通道：绿色边框高亮

### 3. 折线图应急时折叠

- 紧急态默认折叠折线图，空间让给疏散指引
- 可手动展开

### 4. 顶部系统状态大标签

- 🟢 正常运行 / 🔴 紧急疏散
- 颜色醒目，字号大于现有 badge

### 5. 折线图保持一张三线（不改）

v5 已实现。三线并排直观对比出口人数，联动决策依赖此对比。拆开反而削弱。

## 章节大纲（精确到 1.1.1）

### 第3章 系统设计

**3.1 系统总体架构**
  3.1.1 设计目标与原则
    - 双输入冗余、实时性 <1s、可扩展性、低成本
  3.1.2 系统物理架构
    - 架构图：ESP32-CAM → PC(YOLO) → MQTT Broker → ESP8266 → STM32 → 舵机/蜂鸣器/LED
    - 火焰传感器：STM32本地直接响应（不依赖网络）
  3.1.3 系统软件架构
    - 模块划分图：Flask API层 → 检测引擎层 → 决策引擎层 → 通信层 → 硬件执行层
    - 线程模型：3个检测线程 + MQTT线程 + Flask主线程

**3.2 硬件系统设计**
  3.2.1 硬件选型与参数
    - 组件清单表：ESP32-CAM、ESP8266、STM32F103ZET6、SG90舵机、火焰传感器、有源蜂鸣器
    - 各组件关键参数
  3.2.2 STM32 引脚分配与电路连接
    - 引脚映射表：PE5(黄灯) / PB5(红灯) / PB8(蜂鸣器) / PA0(火焰传感器) / PA6(TIM3 PWM) / PA2-PA3(USART2)
    - ESP8266与STM32 UART连接
  3.2.3 执行器控制设计
    - 舵机PWM控制：TIM3 CH1，CCR1值映射（250正转/750停止/1250反转），1200ms动作时长
    - 蜂鸣器+LED三级状态输出
  3.2.4 多场景模拟方案
    - 实物限制说明（1个摄像头、1个舵机、1个火焰传感器）
    - 模拟策略表：3路MP4替代实时流、舵机共享OR逻辑、火焰固定A通道

**3.3 软件系统设计**
  3.3.1 视频采集与AI检测模块
    - MJPEG流手动解析方案、YOLOv8n推理流水线
    - 双视频源支持（MJPEG/MP4 运行时切换）
    - 三通道GPU竞争缓解：相位错开启动（A:0ms, B:16.7ms, C:33.3ms）
  3.3.2 三级报警与防抖机制
    - 报警等级定义表（LV0/LV1/LV2触发条件+硬件输出）
    - 对称防抖算法：连续3帧确认升降级 + 3秒锁定保护
    - 火焰报警最高优先级
  3.3.3 联动决策与引导算法
    - 饱和度计算、四策略决策树（all_clear/guided/degraded/emergency）
    - 每设备独立STM32指令生成
    - 引导算法测试用例（7个场景）
  3.3.4 数据持久化设计
    - SQLite数据库：detection_records + alarm_events 两张表
    - 检测记录按通道写入、报警事件含峰值人数和持续时长
  3.3.5 前端仪表盘设计
    - 页面布局、数据刷新策略（1秒轮询）、应急双态UI
    - 动态折线图：仅活跃通道创建dataset、秒对齐时间轴、spanGaps连线

**3.4 通信协议设计**
  3.4.1 MQTT Topic体系设计
    - 上行Topic、下行Topic、SIG广播Topic
  3.4.2 通信链路数据流设计
    - 下行链路 + 上行链路 + 遗嘱消息机制
  3.4.3 协议健壮性设计
    - UART帧边界、MQTT消息节流、设备通配符订阅自动发现

### 第4章 系统实现与测试

**4.1 系统实现**
  4.1.1 开发环境与工具
    - 后端：Python 3 + Flask + PyTorch + OpenCV + paho-mqtt
    - 固件：Arduino IDE (ESP32/ESP8266) + Keil MDK (STM32)
    - 训练：Ultralytics YOLOv8 + RTX 3060 6GB
    - 版本控制：Git（约80个commits）
  4.1.2 核心模块实现
    - detector.py 检测引擎（detect_loop主循环、_read_mjpeg持久连接、_read_frame统一帧读取）
    - coordinated_decision() 联动决策（快照→饱和度→策略判定→指令生成→MQTT下发）
    - communication.py MQTT通信（通配符回调、遗嘱消息、每设备节流）
    - notify.py 钉钉推送（发送冷却、多通道文案模板）
    - STM32主控固件（servo_tick非阻塞状态机、火焰3帧防抖、UART指令解析）
    - ESP8266透传固件（MQTT连接+LWT+双向串口透传）
  4.1.3 YOLO模型训练
    - 数据集准备、训练参数、模型评估指标

**4.2 系统测试**
  4.2.1 功能测试
    - 三通道视频采集与切换、三级报警触发与防抖
    - 联动决策四策略场景测试（7个标准场景）
    - 硬件联动、钉钉推送、前端仪表盘
  4.2.2 性能测试
    - 视频帧率、YOLO推理速度（三通道并发）
    - 端到端延迟（检测→MQTT下发→STM32响应）
    - MQTT消息可靠性（断线重连、遗嘱消息）
  4.2.3 测试结果分析
    - 各场景通过率统计、性能指标汇总、与设计目标对比

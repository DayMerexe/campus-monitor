# 代码教学 — 校园人流量监控系统

> 为终期答辩准备，逐模块理解系统代码。主对话被论文占用，由多场景对话负责教学。

---

## 任务描述

用户需要能向答辩老师解释"系统怎么做的"。8 课教学计划覆盖从摄像头到硬件的完整链路。

### 教学原则
- 以数据流为主线
- 先讲"为什么"（解决什么问题），再读"怎么做"（关键代码）
- 小粒度模块，避免信息过载
- 随时打断提问

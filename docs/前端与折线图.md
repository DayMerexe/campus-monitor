### 问题 2：折线图与三通道灵活启停不匹配

**现象：**

1. **通道可选启停，但折线图永远三条线**：三通道可以任意打开/关闭，但 chart.js 始终创建三条 dataset，关闭的通道线还在图上（残留旧数据或归零线）。
2. **启动时折线图已有历史记录**：页面打开时用 `PAGE_OPEN_TIME` 过滤 `since` 参数，但 DB 中旧数据仍然存在，关闭再开的通道会带出旧记录。
3. **X 轴时间戳用 A 通道的**：`chart.data.labels` 取 `chHist.A` 的时间，假设三通道时间对齐——但通道是独立启动的，B/C 可能比 A 晚开、早关、或根本没开过。
4. **通道中途关闭后再开，旧线去哪了**：无明确设计。关闭通道的折线是保持、清空、还是灰化？
5. **折线图不能反映系统灵活复杂的使用情况**：比如 A 监控了 10 分钟，B 在第 3 分钟打开、第 8 分钟关闭，C 全程未开——折线图应该清晰呈现这种"各通道独立生命周期"。

**根因：**
折线图设计时假设"三通道一起启动、一起运行、永不停机"，现在系统已支持每通道独立启停+独立视频源切换，折线图没有跟进。

**涉及文件：**
- `campus_monitor/templates/index.html`（chart.js 部分，约 L543-573 创建，L860-871 更新）
- `campus_monitor/db.py`（`get_channel_history` 返回数据格式）
- 可能需要 `campus_monitor/app.py`（新增 API 提供通道时间线数据）

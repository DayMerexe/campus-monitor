## 第二部分：第三章→第四章内容迁移（核心重构）

### 2.1 判断原则

| 属于第三章（总体设计） | 属于第四章（详细设计与实现） |
|--------------------------|------------------------------|
| 架构分几层、每层有什么模块 | 具体引脚编号（PE5、PB5、PA6...） |
| 模块之间怎么连接、用什么协议 | 协议的具体 Topic 前缀值（`bishe/99257/`） |
| 为什么选这个方案（选型理由） | 算法的具体帧数、秒数参数 |
| 数据流的方向和路径 | 代码级的数据处理流程 |
| 核心公式的定义 | 公式的计算流程和边界条件处理 |

**一句话判断标准**：如果某句话删除后，第四章的读者会看不懂代码是怎么写的 → 这句话属于第四章。否则可以留在第三章。

#### 图3-3 四策略联动决策流程图

- **类型**: 流程图（菱形判断 + 矩形处理）
- **流程**:
  1. 开始 → 汇总所有通道状态快照
  2. [判断] 是否有活跃监测通道？→ 否 → all_clear（无活跃通道，无需引导）
  3. 是 → 统计安全通道（排除火灾 + 离线）
  4. [判断] 安全通道数 = 0？→ 是 → emergency（全通道火灾，紧急疏散）
  5. 否 → 计算各安全通道饱和度（= 当前人数 / 预警阈值）
  6. [判断] 所有安全通道饱和度 < 安全上限？→ 是 → all_clear（全线畅通）
  7. 否 → [判断] 存在畅通安全通道？→ 是 → guided（按饱和度升序推荐）
  8. 否 → degraded（降级分批通行）
- **颜色**: all_clear=绿色, guided=蓝色, degraded=橙色, emergency=红色
- **侧边注释**: 饱和度公式 `S_i = N_i / T_yellow_i`

#### 图3-4 系统通信数据流图

- **类型**: 三条并行链路数据流图
- **链路① 下行控制链路（PC→执行器）**:
  PC联动决策 → MQTT Publish → Broker → MQTT Subscribe → ESP8266 → UART → STM32 → GPIO/PWM → 执行器
- **链路② 上行传感链路（传感器→PC）**:
  火焰传感器 → STM32 GPIO → 防抖确认 → UART → ESP8266 → MQTT Publish → Broker → PC MQTT回调 → 更新设备状态字典
- **链路③ 遗嘱消息链路（异常断线感知）**:
  ESP8266 异常断线 → Broker 自动发布遗嘱消息 → PC 收到 offline → 标记设备离线 → 从决策中排除
  ESP8266 重连 → 主动 publish online → PC 标记恢复
- **颜色**: 下行=蓝色, 上行=橙色, 遗嘱=红色虚线

#### 图4-8 STM32 主循环与舵机非阻塞状态机

- **类型**: 主循环流程图 + 舵机子状态机（一图两区）
- **上半区：主循环**
  1. 火焰传感器轮询（连续 N 次低电平→确认火警，连续 N 次高电平→确认解除）
  2. UART 数据检查（按行分隔，检测换行符 `\n`）
  3. 指令解析（键值对：light/buzzer/servo）
  4. 仅在无火焰时更新输出状态（火焰优先级最高）
  5. 舵机状态机检查
  6. 返回循环首部
- **下半区：舵机子状态机**
  - 空闲 → 收到动作指令 → 记录起始时刻 + 设置 PWM（约 1ms/1.5ms/2ms 脉宽）→ 运行中
  - 运行中 → 每周期检查 `now - start ≥ 1200ms` → 是 → 复位 PWM 至停止 → 空闲
- **参数标注**: 火焰确认次数=可配置, 舵机动作时长=1200ms

#### 图4-9 钉钉通知分级冷却流程

- **类型**: 流程图
- **流程**:
  1. 报警事件触发
  2. [判断] 是否火灾？（三通道路径汇总）
  3. 是（红色）→ 即时发送，不检查冷却 → 更新冷却计时器 → 结束
  4. 否 → [判断] 是否等级升级？
  5. 是（橙色）→ 突破冷却，即时发送 → 更新冷却计时器 → 结束
  6. 否 → [判断] 距上次发送超过冷却间隔？
     - 黄色预警冷却间隔 = 60s
     - 红色报警冷却间隔 = 30s
  7. 是（蓝色）→ 发送 → 更新冷却计时器
  8. 否 → 丢弃本次通知（标注"冷却中"）
- **颜色编码**: 红色=火灾直通, 橙色=升级突破, 蓝色=常规冷却, 灰色=丢弃

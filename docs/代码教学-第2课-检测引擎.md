# 第2课：检测引擎 — detector.py 核心

## 这段代码解决什么问题

三个通道同时跑 YOLO 行人检测，需要：
- 每通道独立的视频源（MP4文件 或 MJPEG摄像头）
- 运行时切换源（不动代码）
- 三个人不能抢同一个 GPU，不能卡死

## 核心1: detect_loop(channel) — 检测主循环 (521-717)

```python
def detect_loop(channel):
    # 1. 相位错开 — 避免三路同时抢GPU
    offsets = {'A': 0, 'B': 0.0167, 'C': 0.0333}
    time.sleep(offsets[channel])

    source = None  # 当前视频源对象

    while True:
        # 2. 监测开关 — 暂停时休眠
        if not channel_active.get(channel, False):
            time.sleep(0.5)
            continue

        # 3. 检测源配置变化 — 热切换视频源
        with source_config_lock:
            cfg = source_config.get(channel, ...)
            if cfg changed since last check:
                source = _open_source(channel)  # 打开新源

        # 4. 读一帧
        frame = _read_frame(source)

        # 5. YOLO 推理
        if frame is not None:
            frame_small = cv2.resize(frame, (320, 240))  # 缩到320×240
            results = model(frame_small, conf=0.5, classes=[0])  # 只检测person类
            count = len(results[0].boxes)

        # 6. 三级报警防抖 (第3课详细讲)
        target_level = get_target_level(count, channel)
        # ... 防抖逻辑 ...

        # 7. 更新 channel_state
        with channel_locks[channel]:
            channel_state[channel]['count'] = count
            channel_state[channel]['alarm_level'] = level
            channel_state[channel]['fps'] = fps

        # 8. 每隔0.3s触发联动决策
        if now - last_coord > 0.3:
            coordinated_decision()

        # 9. 帧率上限 20fps
        time.sleep(max(0, 0.05 - elapsed))
```

**关键细节：**
- 模型用 `yolov8n.pt`（n=nano，最小最快），conf=0.5 过滤低置信度
- `classes=[0]` 只检测 person（COCO class 0），忽略其他 79 个类
- resize 到 320×240 再推理（YOLO 的输入不管原图多大都会缩，先缩能减少传输开销）

## 核心2: 视频源管理 — 热切换

```python
# source_config 存用户意图（想用什么源）
source_config[ch] = {'type': 'mp4', 'path': 'videos/a_hallway.mp4', 'url': None}
source_config[ch] = {'type': 'mjpeg', 'path': None, 'url': 'http://192.168.1.100:81/stream'}

# _open_source(channel) 返回实际源对象
# MP4 → cv2.VideoCapture 对象
# MJPEG → ('mjpeg', url) 元组
# MJPEG不可达 → None（显示"摄像头未连接"，不回退）

# _read_frame(source) 统一读帧接口
# isinstance(source, cv2.VideoCapture) → source.read()
# isinstance(source, tuple) and source[0]=='mjpeg' → _read_mjpeg(source[1])
```

**源切换全链路：**
```
前端下拉选源 → applySource() → POST /set_source/{ch} → set_source()
→ source_config 更新 → detect_loop 检测到变化 → _open_source() → 开始读新源
```

**MP4 源的特殊处理：**
- EOF 时 seek(0) 回到开头（而非 close+reopen，避免 0.8s 定格）
- 两个通道不能用同一个 MP4 文件（app.py toggle_monitoring 会检查冲突）

## 核心3: 性能优化 — 三个"相位"

| 优化 | 位置 | 效果 |
|------|------|------|
| detect_loop 相位错开 | 三线程启动后各 sleep 0/16.7/33.3ms | 三路 YOLO 推理不会同时抢 GPU |
| generate_frames 相位错开 | 各差 22ms 发帧 | 三路 JPEG 编码不抢 CPU |
| 帧率上限 20fps | detect_loop sleep(0.05) | 防 GPU 过载 |
| JPEG 质量 60 | cv2.imencode | 降编码开销 |
| coord 节流 0.3s | coordinated_decision | 减少锁竞争 |
